You are in the right folder when this file sits next to a folder named antigravity_mac_migrate.

Do not open antigravity_mac_migrate to run anything. That inner folder is only the program code. It does not contain migrate.sh. migrate.sh is in this same folder, beside antigravity_mac_migrate.

Copy this whole parent folder to the Mac Desktop. On the Mac, quit Antigravity IDE and Antigravity 2.0, open Terminal (Command-Space, type Terminal, press Return), then paste:

cd "$HOME/Desktop"
ls

Find the name that is this parent folder (the one that contains THIS file). Then:

cd "$HOME/Desktop/THAT-NAME"
ls

You must see all of these names on one list:
  START-HERE.txt
  README.md
  pyproject.toml
  migrate.sh
  antigravity_mac_migrate

Then paste:

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e ".[dev]"
python3 -m antigravity_mac_migrate auto --windows-home 'C:\Users\WINDOWS_USER' --mac-home /Users/MAC_USER --also 'D:\work=/Users/MAC_USER/work'

That preview does not change either app. It writes lists on the Desktop.
Copy wanted lines from antigravity-migrate-rename-suggested.txt into antigravity-migrate-rename.txt.
Put workspace paths you do not want attached into antigravity-migrate-drop.txt, one Windows path per line.
Leave antigravity-migrate-keep.txt alone. Those are missing copies, worktrees, and Antigravity internal folders.
antigravity-migrate-pb.txt lists protobuf conversation files. This version does not modify them.

Then, with both apps still quit:

python3 -m antigravity_mac_migrate auto --windows-home 'C:\Users\WINDOWS_USER' --mac-home /Users/MAC_USER --also 'D:\work=/Users/MAC_USER/work' --renames "$HOME/Desktop/antigravity-migrate-rename.txt" --drop "$HOME/Desktop/antigravity-migrate-drop.txt" --apply

Replace WINDOWS_USER and MAC_USER with your real account names. If a destination folder already exists on the Mac, move that whole folder aside before you copy the Windows tree into place. This tool rewrites the copy. It does not merge a live Mac profile.
